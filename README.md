## The entry

> This morning a neighbour I barely know left a still-warm loaf on my doorstep, with a note that just said: welcome home, new girl.

129 characters, one line, written from scratch for this bounty.

## Strategy (why this line)

The judge weighs, in order: on-subject, warmth, surprise, one concrete
detail, fresh wording.

- **On-subject:** one small good thing today, anchored with "This morning".
- **Warmth:** a near-stranger's unasked-for kindness — a loaf left on a
  doorstep — lands as genuinely felt; the note's "welcome home" is the glow.
- **Surprise:** the giver is "a neighbour I barely know" — kindness from
  the last place the reader expects it.
- **Concreteness:** the loaf is "still-warm" and the note is quoted verbatim
  ("welcome home, new girl") — a real small detail, not a general sentiment.
- **Fresh wording:** plain spoken observation with the quoted note as its
  punchline; no greeting-card phrasing.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and self-validates it against the
gate: exactly one line, 1–200 code points, not only whitespace.
Deterministic — the line is a constant; no input, no network, no
randomness. Python 3.13 standard library only.
